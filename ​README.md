# InviteCraft Bot 🎉🤖

An advanced digital invitation card renderer written in Python leveraging Pillow drawing frameworks and async workflow structures.

## 🚀 Step-by-Step Render Deployment Guide

### Step 2: Push All Source Code Direct to the Repository Root
Ensure all target project files (`bot.py`, `handlers.py`, `database.py`, `config.py`, `invitation_generator.py`, `template_manager.py`, `qr_generator.py`, `utils.py`, `requirements.txt`, etc.) are deployed directly into the main index path. Do not pack them into child workspace directories:
```bash
git init
git add .
git commit -m "Initialize structural footprint build files for InviteCraft Engine"
git branch -M main
git remote add origin [https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git)
git push -u origin main
